# Security Policy

## Supported Versions

Currently, only the latest release of Vocalis is supported with security updates.

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

Please do not report security vulnerabilities through public GitHub issues.

Instead, please send an email to the repository maintainers. If a vulnerability is confirmed, we will release a patch as soon as possible.
